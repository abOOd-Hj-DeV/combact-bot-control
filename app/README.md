# Combact Controller — Android app

تطبيق Flutter للتحكم بالروبوت عبر UDP @ 50Hz.

## الاستخدام | Usage

1. شغّل الروبوت — تظهر شبكة `COMBACT-BOT`.
2. اتصل بها من إعدادات WiFi على الموبايل.
3. افتح التطبيق. شريط الحالة يعرض: حالة الاتصال، جهد البطارية، RSSI، معدل الاستقبال، الرزم الضائعة.

> التطبيق يعمل `bindProcessToNetwork` تلقائياً حتى لا يحوّل أندرويد الترافيك لبيانات الجوال. إذا ما اشتغل الإرسال، طفّي بيانات الجوال مؤقتاً.

## الواجهة | Controls

| العنصر | الوظيفة |
|---|---|
| الجويستيك (يسار) | قيادة: عمودي = throttle، أفقي = steering |
| مفتاح ARM | تسليح المطرقة — أحمر = مسلّحة |
| سلايدر HAMMER | سرعة المطرقة التناسبية (أعلى = أمام، أسفل = عكس)، يرجع للصفر عند الإفلات |
| زر FIRE | دفعة كاملة للمطرقة ما دمت ضاغطاً |
| INVERT | قلب اتجاه القيادة (إذا الروبوت مقلوب) |
| LOW | وضع دقة — 40% من القوة |

## البناء | Build

```bash
flutter pub get
flutter analyze        # نظيف
flutter test           # اختبارات البروتوكول
flutter build apk --release   # APK: build/app/outputs/flutter-apk/
```

التطبيق يعمل بوضع أفقي فقط والشاشة تبقى مضاءة أثناء القيادة.
